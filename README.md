# EventHub - Frontend

Frontend del proyecto final EventHub.

## Tecnologías
- Vue 3
- Vite
- Vue Router
- JavaScript

## Funcionalidades implementadas

- Pantalla de inicio de sesión.
- Registro de usuarios.
- Inicio de sesión con Google.
- Verificación de correo electrónico.
- Recuperación y restablecimiento de contraseña.
- Dashboard de usuario.
- Comunicación con el backend de EventHub.

## Requisitos

- Node.js y npm.
- Backend de EventHub configurado y funcionando.

## Instalación

1. Clonar el repositorio:

git clone https://github.com/dr47988-ops/Proyecto-Final-EventHub-Frontend.git

2. Entrar a la carpeta:

cd Proyecto-Final-EventHub-Frontend

3. Instalar dependencias:

npm install

4. Crear un archivo .env en la raíz del frontend.

5. Agregar la siguiente variable:

VITE_GOOGLE_CLIENT_ID=

El valor debe corresponder al cliente OAuth de Google configurado para EventHub.

No subir archivos .env a GitHub.

## Ejecutar el frontend

npm run dev

Abrir en el navegador:

http://localhost:5173/

## Backend

Repositorio:
https://github.com/dr47988-ops/Proyecto-Final-EventHub-Backend

El backend debe estar ejecutándose en:

http://localhost:3000
